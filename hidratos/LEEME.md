# Subir al repo
Copia el contenido de esta carpeta dentro de `hidratos/` de tu repo `menucomedor`, sustituyendo el `index.html` actual:

    hidratos/
    ├── index.html            (ya lleva el manifest, iconos y registro del service worker)
    ├── manifest.webmanifest
    ├── sw.js
    └── icons/ (5 png)

Instalar en Android: abre https://oscargf1982.github.io/menucomedor/hidratos/ en Chrome → menú ⋮ → "Instalar aplicación".
Si tras cambios ves contenido antiguo, sube VERSION en sw.js (v1 → v2).
